# ASTROVERSE EXPLORE
Updated starter with the new branding and an interactive animated Three.js solar-system hero.

- A true WebGL 3D solar system with the Sun and eight orbiting planets.
- Drag to rotate the scene; pinch/scroll to zoom.
- Responsive for mobile and desktop.
- Bengali uses Hind Siliguri; English uses Orbitron.
- Three.js is loaded from jsDelivr; internet is required for the 3D scene.
- An import map is included so OrbitControls can resolve the `three` module correctly.

## Deploy from mobile
Replace the existing `index.html` in the connected GitHub repository with this one and commit the change. Vercel should redeploy automatically.

Note: this build adds a 3D animated solar-system hero. The detailed zoomable Earth globe, country boundaries and live satellite positions are not yet implemented. Planet sizes and distances are illustrative, not to scale.
